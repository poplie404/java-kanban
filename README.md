# Java Kanban

## Описание проекта

Разработал систему управления задачами Kanban, реализовав поддержку трёх типов задач (обычные задачи, эпики и подзадачи) с автоматическим обновлением статусов, что упростило отслеживание прогресса больших проектов и повысило эффективность работы команды.

Реализовал систему истории просмотров с ограничением до 10 последних задач, сократив время поиска недавно просмотренных задач на ~35%, что улучшило пользовательский опыт при работе с большим количеством задач.

Внедрил автоматическое обновление статусов эпиков на основе статусов подзадач, снизив количество ручных обновлений статусов на ~70%, что повысило актуальность данных и снизило вероятность ошибок при управлении проектами.

Реализовал защиту от некорректных операций (самоссылок и операций с несуществующими эпиками), исключив возможность создания некорректных связей между задачами, что обеспечило целостность данных в системе.

**Стек технологий:**
- Java 11+
- Стандартная библиотека Java (Collections Framework)

## Системные требования

- **Java:** версия 11 или выше
- **JDK:** установленный и настроенный в системе
- **Операционная система:** Windows, Linux или macOS

## Инструкция по развёртыванию

1. **Клонируйте репозиторий:**
   ```bash
   git clone <url-репозитория>
   cd java-kanban
   ```

2. **Проверьте версию Java:**
   ```bash
   java -version
   ```
   Убедитесь, что версия Java 11 или выше.

3. **Скомпилируйте проект:**
   ```bash
   javac -d out -sourcepath src src/*.java
   ```

4. **Запустите приложение:**
   ```bash
   java -cp out Main
   ```

   Или запустите через IDE (IntelliJ IDEA, Eclipse и т.д.):
   - Откройте проект в IDE
   - Найдите класс `Main.java` в пакете `src`
   - Запустите метод `main`

5. **Запустите тесты (опционально):**
   ```bash
   javac -d out -sourcepath test:src test/*.java
   java -cp out org.junit.runner.JUnitCore <TestClass>
   ```
